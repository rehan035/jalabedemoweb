# Grato Jalebi — Lahore · Haute Confectionery

An artisanal luxury confectionery web application for **Grato Jalebi Lahore**, crafted in the **Royal Heritage Confectionery** design system.

## Features

- **Editorial Hero & Live Batch Status**: Showcasing the 90-second pure desi ghee fry ritual, 24-hour wild overnight fermentation, and real-time kadhai batch metrics.
- **Interactive Menu & Category Filtering**: Filter between *Signature Jalebi*, *Hand-Folded Samosas*, *Savouries & Snacks*, and *Family Combos*.
- **Slide-Over WhatsApp Confection Box (Cart Drawer)**: Live subtotal calculation, branch dispatch selection, custom preparation notes, one-tap WhatsApp order routing (`+92 305 743 7708`), and clipboard order summary copy.
- **Lahore Flagship Kitchen Selector**: Switch between *Walton Flagship*, *DHA Phase 2*, *Johar Town*, and *Bahria Town* with operating hours, landmarks, Google Maps links, and direct branch dispatch links.
- **Royal Heritage Confectionery Design System**: Built with `Playfair Display` and `Plus Jakarta Sans` typography, warm ivory (`#fbf9f5`), saffron mahogany (`#2E0B0E`), deep burgundy night (`#1F0709`), and antique amber (`#C27803`).
